# Fun tools for managing everyday works
### Author: Puspendu Sardar, Ph.D., Deprtment of Medicine, University of Cambridge

This repository contains scripts for basic analyses and utilities of daily life.

## Tools Included

1. **compress_image.py**: Python script to compress image files.
   - Usage: `python3 compress_image.py -h`

2. **wordcloud_cli.py**: Python script to make beutiful worlclouds from a given input text-list and an image.
   - Usage: `python3 wordcloud_cli.py -h`
